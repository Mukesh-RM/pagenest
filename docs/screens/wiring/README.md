# Wired screens at 360 px

Screenshots of the real app (production build of `feature/wire-redesign` at a6c3be9, after the
lazy-loading change) at a 360 × 740 phone viewport, 2× pixel ratio, taken with touch input. The
Library has a few sample rows added to the local database; the sample-book card shown in 01 and 05
uses a fake in-memory provider (the real one comes from the Library bot). Docs only: nothing in the
app reads these files. PNGs are palette-optimised to keep this folder small.
